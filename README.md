# プロジェクト概要（全体）

本リポジトリは、本サービスの **バックエンド / フロントエンドを含む全体構成** を管理するためのプロジェクトです。

各コンポーネントは役割ごとに分離されており、詳細な仕様やセットアップ手順はそれぞれの README を参照してください。

---

## 全体構成

本プロジェクトは、主に以下のコンポーネントで構成されています。

* **Backend**

  * API サーバー
  * 認証・データ管理・ビジネスロジック

* **Frontend（Mobile App）**

  * Flutter 製モバイルアプリ（iOS / Android）
  * UI / 状態管理 / ドメインロジック
